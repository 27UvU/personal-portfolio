学习内容

第1章：Numpy基础

1.1 Numpy数组创建

学习使用Numpy创建数组，掌握各种数组创建方法。

import numpy as np

# 创建数组
arr1 = np.array([1, 2, 3, 4, 5])
arr2 = np.zeros(5)
arr3 = np.ones((2, 3))
arr4 = np.arange(1, 10, 2)

print(arr1)
print(arr3)

第2章：Pandas入门

2.1 Series与DataFrame

学习Pandas的核心数据结构Series和DataFrame。

import pandas as pd

# 创建Series
data = [10, 20, 30, 40, 50]
s = pd.Series(data, index=['a', 'b', 'c', 'd', 'e'])

# 创建DataFrame
data = {
    '姓名': ['张三', '李四', '王五'],
    '年龄': [20, 21, 22],
    '成绩': [85, 90, 78]
}
df = pd.DataFrame(data)
print(df)
