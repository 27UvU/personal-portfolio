学习内容

第1章：Python入门

1.1 Python简介与安装

了解Python的特点、应用领域，学习如何安装Python配置开发环境。

# Python 安装后检查版本
python --version

# 或
python3 --version

1.2 第一个Python程序

学习如何编写并运行第一个Python程序，了解代码结构。

# 第一个 Python 程序
print("Hello, World!")
print("欢迎学习 Python 编程！")

1.3 变量与数据类型

学习变量的命名规则、Python的基本数据类型。

# 变量与数据类型
name = "张三"          # 字符串
age = 20              # 整数
height = 1.75         # 浮点数
is_student = True     # 布尔值

# 输出变量值
print(f"姓名：{name}")
print(f"年龄：{age}")
print(f"身高：{height}米")

第2章：流程控制

2.1 条件语句

学习使用条件语句进行逻辑判断。

# 条件语句示例
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

2.2 循环语句

学习使用for循环和while循环进行重复操作。

# for循环示例
for i in range(1, 6):
    print(f"第{i}次循环")

# while循环示例
count = 0
while count < 5:
    print(f"计数：{count}")
    count += 1

习题

第1章：Python入门习题

习题1：个人信息输出

定义变量存储你的姓名、年龄、学校，然后格式化输出这些信息。

提示：

使用字符串格式化（f-string）来组织输出内容。

习题2：简单计算器

编写程序，输入两个数字，输出它们的和、差、积、商。

提示：

使用 input() 函数获取用户输入，注意转换为数值类型。

第2章：流程控制习题

习题1：成绩等级判定

输入一个分数，输出对应的等级（A/B/C/D/E）。

提示：

使用 if-elif-else 语句进行多条件判断。

习题2：九九乘法表

使用嵌套循环打印九九乘法表。

提示：

外层循环控制行数，内层循环控制每行的列数。
