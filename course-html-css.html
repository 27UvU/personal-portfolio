学习内容

第1章：HTML基础

1.1 HTML简介与历史

HTML（HyperText Markup Language）是用于创建网页的标准标记语言。本节将介绍HTML的发展历史、版本演进以及其在网页开发中的重要性。

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>

1.2 HTML基本结构

了解HTML文档的基本结构，包括DOCTYPE声明、html、head和body标签的作用。

1.3 常用HTML标签

学习常用的HTML标签，如标题标签（h1-h6）、段落标签（p）、链接标签（a）、图片标签（img）等。

1.4 语义化标签

了解HTML5引入的语义化标签，如header、nav、section、article、footer等，以及它们在网页结构中的应用。

1.5 HTML表单

学习HTML表单的创建，包括表单元素（input、textarea、select等）和表单属性。

第2章：CSS基础

2.1 CSS简介

CSS（Cascading Style Sheets）用于描述HTML元素的显示方式。本节将介绍CSS的基本概念和作用。

2.2 CSS选择器

学习CSS选择器的种类和使用方法，包括元素选择器、类选择器、ID选择器、后代选择器等。

/* 元素选择器 */
p {
    color: #333;
}

/* 类选择器 */
.button {
    background-color: #2563eb;
    color: white;
}

/* ID选择器 */
#header {
    font-size: 24px;
}

2.3 CSS样式属性

学习常用的CSS样式属性，如颜色、字体、边距、背景等。

2.4 盒模型

了解CSS盒模型的概念，包括内容区、内边距、边框和外边距。

2.5 浮动与定位

学习CSS的浮动（float）和定位（position）属性，以及它们在布局中的应用。

习题

第1章：HTML基础习题

习题1：创建基本HTML结构

创建一个包含标题、段落、链接和图片的基本HTML页面。

提示：

使用h1-h6标签创建标题，p标签创建段落，a标签创建链接，img标签添加图片。

习题2：创建语义化HTML结构

使用HTML5语义化标签创建一个包含页眉、导航栏、主要内容和页脚的网页结构。

提示：

使用header、nav、main、section、article、footer等语义化标签。

习题3：创建HTML表单

创建一个包含文本输入框、密码输入框、单选按钮、复选框和提交按钮的表单。

提示：

使用form、input、label、button等标签创建表单。

第2章：CSS基础习题

习题1：基本CSS样式

为上一章创建的HTML页面添加CSS样式，设置字体、颜色、边距等。

提示：

使用内联样式、内部样式表或外部样式表为HTML元素添加样式。

习题2：CSS选择器练习

使用不同类型的CSS选择器为页面中的元素添加不同的样式。

提示：

尝试使用元素选择器、类选择器、ID选择器、后代选择器等。

习题3：盒模型练习

创建一个带有内边距、边框和外边距的元素，并观察盒模型的效果。

提示：

使用padding、border、margin属性设置盒模型的各个部分。
