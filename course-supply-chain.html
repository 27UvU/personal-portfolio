第2章：需求预测

2.1-2.3 移动平均与指数平滑

学习使用Python实现移动平均和指数平滑预测。

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 创建示例数据
data = pd.DataFrame({
    '月份': range(1, 13),
    '销量': [100, 120, 110, 130, 140, 150, 145, 155, 165, 160, 170, 180]
})

# 移动平均
data['MA3'] = data['销量'].rolling(3).mean()

# 指数平滑
data['EMA'] = data['销量'].ewm(alpha=0.3).mean()

print(data)

第3章：库存优化

3.3 ABC分类法

学习ABC分类方法，对库存进行优先级管理。

import pandas as pd

products = pd.DataFrame({
    '产品': ['A', 'B', 'C', 'D', 'E'],
    '年销量': [10000, 8000, 5000, 2000, 500],
    '单价': [100, 200, 150, 300, 400]
})

products['销售额'] = products['年销量'] * products['单价']
products = products.sort_values('销售额', ascending=False)
products['累计占比'] = products['销售额'].cumsum() / products['销售额'].sum()

# ABC分类
products['类别'] = pd.cut(
    products['累计占比'],
    bins=[0, 0.8, 0.95, 1],
    labels=['A', 'B', 'C']
)

print(products)
