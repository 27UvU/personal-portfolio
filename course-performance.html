学习内容

第1章：性能优化基础

1.1 性能优化的重要性

了解前端性能优化的重要性，包括对用户体验、SEO和业务转化的影响。

1.2 性能指标

学习常用的性能指标，如LCP（最大内容绘制）、FID（首次输入延迟）、CLS（累积布局偏移）等。

1.3 性能测试工具

学习使用Chrome DevTools、Lighthouse、WebPageTest等工具进行性能测试。

// 使用Lighthouse进行性能测试
// 在Chrome DevTools中打开Lighthouse标签页
// 或使用命令行工具
npm install -g lighthouse
lighthouse https://example.com

1.4 性能分析方法

学习如何分析性能瓶颈，确定优化方向。

第2章：资源优化

2.1 图片优化

学习图片格式选择、压缩、响应式图片等优化技巧。

<!-- 使用响应式图片 -->
<picture>
    <source media="(max-width: 768px)" srcset="image-small.webp" type="image/webp">
    <source media="(max-width: 768px)" srcset="image-small.jpg" type="image/jpeg">
    <source srcset="image-large.webp" type="image/webp">
    <img src="image-large.jpg" alt="示例图片" loading="lazy">
</picture>

2.2 CSS优化

学习CSS选择器优化、CSS压缩、CSS-in-JS等优化技巧。

2.3 JavaScript优化

学习JavaScript代码分割、压缩、Tree Shaking等优化技巧。

2.4 字体优化

学习字体加载策略、字体子集化等优化技巧。

// 字体加载策略
@font-face {
    font-family: 'MyFont';
    src: url('myfont.woff2') format('woff2'),
         url('myfont.woff') format('woff');
    font-display: swap;
}

习题

第1章：性能优化基础习题

习题1：性能测试

使用Lighthouse测试一个网站的性能，并分析结果。

提示：

访问网站，打开Chrome DevTools，切换到Lighthouse标签页，运行性能测试。

习题2：性能指标分析

分析一个网站的LCP、FID、CLS等性能指标，并找出优化方向。

提示：

使用Lighthouse或WebPageTest获取性能指标。

第2章：资源优化习题

习题1：图片优化

优化一个网站的图片，包括格式转换、压缩等。

提示：

使用工具如Squoosh或TinyPNG进行图片压缩。

习题2：CSS优化

优化一个网站的CSS，包括选择器优化、压缩等。

提示：

使用工具如PurgeCSS去除未使用的CSS。

习题3：JavaScript优化

优化一个网站的JavaScript，包括代码分割、压缩等。

提示：

使用Webpack或Vite进行代码分割和压缩。
